## 進める順番の理由

- 1→2 が一番大事。要約が無いと、3〜5 はどれも成り立たない。
- 5 は 1 と同時でも作れる（GAS の save を触るだけ）。ただし 0 の「GAS のアカウント」が決まらないと、PC から見える場所かどうかが分からない。
- 7 は SuperFlow の機能を全部まねるためではなく、使ってみて足りなかったものだけ足す。
