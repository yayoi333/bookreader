# よみあげ文庫（第二の脳）の読み方

## 場所

- 目次：`C:\Users\akiru\Google ドライブ ストリーミング\マイドライブ\よみあげ文庫\md\INDEX.md`
- 記事：同じ `md` フォルダの `YYYYMMDD-タイトル.md`（日付は元記事の公開日、無ければ保存日）
- Google ドライブ（info@threeehearts.com）がPCに同期している場所。アプリ「よみあげ文庫」とGASが自動で書き出す。

## 手順（必ずこの順）

1. **`INDEX.md` だけを読む。** 1記事1行の表（公開日・保存日・タイトル・状態・読む価値・要約1行・ファイル）。
2. 質問に関係しそうな行を選ぶ。「先週」「最近」は保存日、「〜という記事」はタイトルと要約1行で判断する。状態（未読／あとで／読了）で絞れと言われたら状態の列を見る。
3. 選んだ行の **ファイルだけ** を開く。まず先頭の「## 要約」までを読み、それで答えられなければ「## 本文」を読む。
4. 答えには、使った記事のタイトルと元URL（ファイル先頭の `url:`）を添える。

## してはいけないこと

- `md` フォルダのファイルを全部読む、全文を grep して当たったものを全部開く（目次を飛ばすと遅く、量も多い）。
- 記事ファイルや目次を書き換える・消す。ここは読むだけ。状態の変更や削除はアプリでユーザーが行う。
- 目次に無い記事を「保存されていない」と言い切る前に、目次の更新日時を確かめる（アプリからの書き出しが遅れていることがある）。

## 困ったとき

- `INDEX.md` が無い：アプリでDrive連携（GAS）が未設定か、まだ1本も書き出されていない。GASで `exportAllDocsToMd` を実行すると、保存済みの文書が書き出される。
- 目次の行はあるのにファイルが無い：Google ドライブの同期待ちの可能性。少し待つか、ファイル名で `md` フォルダを確認する。
